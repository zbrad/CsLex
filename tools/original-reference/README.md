# Original-generator reference

`LexTests/Golden/*.tokens.txt` are not produced by the current generator. They
are the output of lexers generated by the original 1999 CsLex (`lex/src`, tag
`original-1999`), built unchanged on the .NET 10 SDK and run on
`LexFiles/test.txt`. The end-to-end tests therefore check the current
generator against the original behavior.

To check or regenerate them:

    tools/original-reference/reproduce.sh            # compare
    tools/original-reference/reproduce.sh --update   # overwrite the goldens

Recorded with .NET SDK 10.0.403 on linux-x64 with
`DOTNET_SYSTEM_GLOBALIZATION_INVARIANT=1` (the host had no ICU). The sample
specs use no case-insensitive matching, so the result shouldn't depend on ICU.
That is expected, not tested.

`CSLEX_UPDATE_GOLDEN=1` in the test suite deliberately does not touch these
files.
